HOW TO ADD YOUR REAL PHOTOS & MUSIC
====================================

Drop files into this folder using the exact names below. The website
will pick them up automatically — no code changes needed. Until a file
is added, an elegant placeholder is shown in its place.

  couple-hero.svg     Hero + final section background   (currently an illustrated
                      dummy couple-from-behind placeholder — replace with a real
                      landscape photo, 1920x1080 or larger, and point
                      images.coupleHero at it in js/config.js)
  first-meeting.jpg   "The First Step" section photo     (portrait, 4:5)
  groom-letter.jpg    Scanned handwritten letter photo   (portrait, 3:4)
  groom.jpg           Groom's portrait                   (square, 800x800)
  bride.jpg           Bride's portrait                   (square, 800x800)
  family-bride.jpg    Bride's family photo                (landscape, 16:10)
  family-groom.jpg    Groom's family photo                (landscape, 16:10)
  venue.svg           Wedding venue photo                 (currently a placeholder
                      card with Sonai Palace's name on it — replace with a real
                      landscape photo, 16:9, and point images.venue at it)
  gallery-01.jpg      Gallery photo — "Our Beginning"
  gallery-02.jpg      Gallery photo — "Family"
  gallery-03.jpg      Gallery photo — "Memories"
  gallery-04.jpg      Gallery photo — "Wedding Moments"
  gallery-05.jpg      Gallery photo — "Family"
  gallery-06.jpg      Gallery photo — "Memories"
  wedding-music.mp3   Optional background music

To change filenames, categories, or add more gallery photos, edit the
"images" and "music" sections inside /js/config.js — everything else
on the site (names, dates, story text, venue, timeline) is also edited
from that single file.
